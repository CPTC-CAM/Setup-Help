# GitHub Copilot Pro
This document is to help current students sign up for and get verified on GitHub
for GitHub Pro and GitHub Copilot Pro

## Set up for success
These steps should help prevent your verification attempts from being marked as spam
and getting rejected
- Go to your profile -> Settings -> Billing and Licensing -> Payment Information
  - Fill out your address
- Go to your profile -> Settings -> Password and Authentication
  - Activate 2FA
- Profile -> Settings -> Public Profile
  - Type your full legal name as your name
 
## Verify Student Status
- https://github.com/education/students : Verify your account for student benefits
  - It is recommended to get a Student ID and take a picture in the verification process
